# {{APP_NAME}}

Generated by the **AI SaaS Factory**. An Express (TypeScript) + Prisma API
(`api/`) and a React (Vite) SPA (`web/`), with JWT auth and a sample `items`
CRUD resource. Uses SQLite for a zero-infra start; swap to Postgres for scale.

## Run locally

```bash
cp .env.example .env
docker compose up --build
```

- Frontend: http://localhost:3000
- API: http://localhost:8000/health

## Test

```bash
cd api && npm install && npm test    # spins up an ephemeral SQLite schema
```
